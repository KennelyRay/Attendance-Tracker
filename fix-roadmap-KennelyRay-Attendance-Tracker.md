## 🔴 P0 — Critical (fix immediately)

### 1. Default session secret lets attackers forge admin cookies
**File:** `src/lib/session.ts`

**Why it matters:** If this app is deployed without setting SESSION_SECRET, anyone who knows the public fallback string can mint their own admin login cookie and take over the whole system.

**How to fix it:**
Remove the hardcoded fallback and fail closed: set sessionOptions.password to process.env.SESSION_SECRET only, and throw during boot if it is missing or shorter than a strong random value. Rotate the secret in production so any forged cookies become invalid, and force all users to sign in again. Fixing this prevents full admin takeover from a single leaked default string.

## 🟡 P2 — Medium (fix this sprint)

### 1. Raw server error messages are returned to clients in admin leave review API
**File:** `src/app/api/admin/leave-requests/route.ts`

**Why it matters:** Attackers can make the server tell them internal validation and database details that help them map your system and plan the next attack.

**How to fix it:**
Return generic client-safe errors from the route, such as 'Invalid request' or 'Unable to process leave review', and log the detailed exception only on the server. If you need structured validation feedback, whitelist specific safe messages instead of returning arbitrary error.message. Fixing this reduces useful recon data attackers can harvest before exploiting a more serious issue.

### 2. Raw server error messages are returned to clients in admin violations APIs
**File:** `src/app/api/admin/violations/route.ts`

**Why it matters:** A malicious user can probe these endpoints and get internal error text back, which makes finding and exploiting other weaknesses much easier.

**How to fix it:**
Replace raw error.message responses with generic safe responses, for example 'Invalid violation payload' or 'Unable to update violation', and keep full details only in server logs. If specific field errors are needed, validate input explicitly and return a controlled whitelist of messages. Fixing this cuts off free reconnaissance that helps attackers weaponize other bugs.
